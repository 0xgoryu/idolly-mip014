# MIP 014 Offchain Lab

A Linux style offchain simulator for demonstrating MIP 014 behavior.

## Deploy on Vercel

1. Upload the project folder to GitHub or directly import it into Vercel.
2. Vercel will detect it as a static site.
3. No build command is required.

## Files

- `index.html`
- `styles.css`
- `app.js`
- `vercel.json`

## Features

- Linux inspired UI
- Offchain agent registry simulation
- Identity registration flow
- Executive and delegation simulation
- Execution and revocation flow
- Persistent local state in the browser
