How MIP 014 works offchain
01

Create an agent

The simulator mints a local agent record and generates a deterministic looking identity address from the agent name.

02

Attach identity

The registry marks the agent as active and attaches a plugin flag that behaves like an identity layer.

03

Assign an executive

A wallet or operator becomes the allowed executor, which mirrors the delegation model in the proposal.

04

Simulate execution

Actions are checked against permissions, then written into the local transaction log with fake hashes and outcomes.

Protocol model
agent → identityPDA → executive → permission check → execution log
