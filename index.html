/ What is MIP-014

The Onchain Passport
for AI Agents

MIP-014 stands for Metaplex Improvement Proposal #14 — the standard that introduces the Agent Registry to the Solana blockchain.

Think of it like a government passport system, but entirely on-chain and open-source. Each AI agent gets a unique, cryptographically verifiable identity record attached to an MPL Core asset.

This means any wallet, dApp, or other agent can look up and trust an agent's identity without any central authority. It's the foundation for Agent-to-Agent (A2A) commerce — autonomous AI transactions between agents that don't require human approval for every step.

Metaplex launched MIP-014 with 14 early adopter projects committed to building on this standard — and IdollyAI is part of that ecosystem.

/ How It Works

From Asset to
Autonomous Agent

01

Register Agent Identity

A creator calls RegisterIdentityV1 with an MPL Core NFT and a registration URI. The Agent Identity program creates a PDA (Program Derived Address) tied to that asset, making the agent permanently discoverable on-chain.

02

Attach AgentIdentity Plugin

The program attaches an AgentIdentity plugin to the Core asset with lifecycle hooks for Transfer, Update, and Execute events. This means the agent can now sign transactions and act autonomously — the asset itself becomes a signer.

03

Create Executive Profile

An executive (a human or another program) registers via RegisterExecutiveV1. This is the entity that will operate the agent — like handing the passport to a trusted pilot.

04

Delegate Execution

The asset owner calls DelegateExecutionV1 to grant the executive permission to act on behalf of the agent. A delegation record PDA is created linking the executive to the asset — all on-chain, all auditable.

05

Agent Acts Autonomously

The agent can now hold funds, sign transactions, swap tokens, and interact with other agents — all within the permissions granted. This is the foundation of Agent-to-Agent (A2A) commerce on Solana.

/ Glossary

Key Terms
for New Members

MIP-014
Metaplex Improvement Proposal #14 — the on-chain agent identity standard for Solana. Defines how AI agents get verified, discoverable identities.
MPL Core
Metaplex's next-generation NFT standard with a composable plugin system. It's what IdollyAI idols are built on.
PDA
Program Derived Address — a special Solana account address generated deterministically from a program's logic. Used to store agent identity records securely.
cNFT
Compressed NFT — NFTs stored using a Merkle Tree, costing up to 99% less than regular NFTs. IdollyAI uses these to let anyone mint for free.
Delegation
Granting another wallet or program permission to act on behalf of an agent. Recorded on-chain via a delegation PDA so it's fully auditable.
A2A Commerce
Agent-to-Agent Commerce — autonomous transactions between AI agents without human intervention. MIP-014 enables this by giving agents trusted identities.
$DOLLIZ
The community token of IdollyAI. An SPL token on Solana used for rewards, interactions, and future governance of the IdollyAI ecosystem.
Bubblegum
The Metaplex compressed NFT program. IdollyAI uses it to mint idol cNFTs efficiently and affordably using Merkle Trees.
